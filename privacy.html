Privacy Policy

Last updated: 6 October 2026

Sharp Cuts Uploader ("the app") is a private tool operated by the owner of the YouTube channels @sharpcutsdaily and @Cage_Clock. It is used only by its operator to upload, schedule and manage videos on the operator's own channels.

Data the app accesses

When the operator signs in with Google, the app receives an OAuth token for the YouTube Data API and, where granted, the YouTube Analytics API. It uses this token only to upload and update videos on the operator's own channel and to read that channel's statistics.

Storage and sharing

The OAuth token is stored only on the operator's own computer. The app does not collect, sell or share any personal data, does not access data of any other Google user and does not use data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
